# Knowledge library

A library preserves source texts and accepted knowledge, and lets readers trace a quotation to a specific source revision.

## Language

**Library**: An explicitly scoped collection of sources, accepted knowledge, relationships, and research records. A library boundary does not itself grant access.

**Source revision**: An immutable captured version of a source's original bytes and provenance. A later revision never changes the meaning of a citation to an earlier one.

**Accepted knowledge**: Human edits and approved compilations that must survive rebuilding retrieval data.
_Avoid_: Generated cache

**Evidence**: A quoted original span from one identified source revision. Its existence proves the quotation's location, not every inference in an answer.
_Avoid_: Consulted document

**Draft**: A proposed knowledge revision awaiting explicit application. Producing a draft does not accept it.

**Retrieval generation**: A compatible set of derived passages and representations used together for retrieval.
